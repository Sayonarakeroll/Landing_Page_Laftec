# LAFTEC - Liga Acadêmica de Tecnologia Feminina


Este é o repositório da landing page oficial da **LAFTEC (Liga Acadêmica de Tecnologia Feminina)**. O projeto foi desenvolvido para apresentar a liga, suas ações, seu time e formas de contato.

## Projeto

A LAFTEC é uma iniciativa comprometida em promover um espaço inclusivo e acolhedor para mulheres na tecnologia. O propósito da liga é reduzir as barreiras de gênero, ampliar a diversidade e criar oportunidades reais de crescimento e protagonismo feminino no setor.

Esta página serve como um portal central para divulgar as ações da liga, além de apresentar a equipe e os eventos.

##  Tecnologias Utilizadas

Este projeto foi construído utilizando :

-   **Framework:** [Next.js](https://nextjs.org/)
-   **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
-   **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
-   **Componentes UI:** [Shadcn/ui](https://ui.shadcn.com/)
-   **Ícones:** [Lucide React](https://lucide.dev/)
-   **Gerenciador de Pacotes:** [pnpm](https://pnpm.io/)

##  Como Executar o Projeto

Siga os passos abaixo para configurar e rodar o projeto em seu ambiente de desenvolvimento local.

### Pré-requisitos

-   [Node.js](https://nodejs.org/) (versão 20.x ou superior)
-   [pnpm](https://pnpm.io/)

### Instalação

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Sayonarakeroll/Landing_Page_Laftec.git
    cd laftec-landing
    ```

2.  **Instale as dependências:**
    O projeto utiliza `pnpm`. Use o seguinte comando para instalar todas as dependências necessárias:
    ```bash
    pnpm install
    ```

3.  **Inicie o servidor de desenvolvimento:**
    Após a instalação, rode o comando abaixo para iniciar o servidor local:
    ```bash
    pnpm dev
    ```

4.  **Acesse a aplicação:**
    Abra seu navegador e acesse [http://localhost:3000](http://localhost:3000) para ver a aplicação em execução.
